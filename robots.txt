# --- 모델 학습용 (차단) ---
# Cloudflare 의 AI 스크래퍼 차단 기능이 이 크롤러들을 엣지에서 403 으로
# 막고 있다. 답변에 인용을 만들어내지 않는 학습 전용 수집이라 막아 두고,
# robots.txt 도 실제 동작과 같게 맞춘다.
# 다시 허용하려면 Cloudflare 대시보드(Security → Bots)에서 차단을 끄고
# 아래 Disallow 를 Allow 로 되돌려야 한다. 한쪽만 바꾸면 어긋난다.
User-agent: GPTBot
Disallow: /

User-agent: ClaudeBot
Disallow: /

# Common Crawl. 역시 Cloudflare 에서 차단 중이다.
User-agent: CCBot

# 둘을 나눠 고를 수 없다. 막으면 학습도 막지만 Gemini 답변에 인용될
# 길도 함께 닫히므로 열어 둔다. 위의 학습용 차단과 기준이 다른 이유다.
# 허용/차단 어느 쪽이든 구글 검색 색인과 순위에는 영향이 없다.
