# 🏛️ 법률사무소 세영 (오세영 변호사) 공식 웹사이트

신뢰받는 법률 파트너, **오세영 대표변호사**의 전문 브랜딩 및 원페이지(SPA) 공식 웹사이트입니다.

---

## 🌟 주요 특징
- **클래식 & 신뢰감 높은 디자인**: 딥 네이비(`Deep Navy`)와 웜 골드(`Warm Gold`) 톤의 프리미엄 브랜딩
- **모듈화된 웹 표준 구조**: `HTML`, `CSS`, `JS`로 깔끔하게 분리된 아키텍처
- **반응형 레이아웃**: 데스크톱, 태블릿, 모바일 완벽 대응
- **인터랙티브 기능**:
  - 모바일 햄버거 메뉴 토글
  - 섹션 겹침(Overlap) 레이아웃
  - 1:1 무료 법률 상담 신청 및 폼 검증

---

## 📁 프로젝트 파일 구조
```
├── index.html       # 메인 웹페이지 시맨틱 마크업
├── style.css        # 커스텀 섀도우 및 클리핑 스타일시트
├── script.js        # Tailwind 설정 및 UI 인터랙션 스크립트
├── screenshot.png   # 디자인 프리뷰 스크린샷
└── README.md        # 프로젝트 소개 문서
```

---

## 🚀 시작하기
별도의 빌드 도구 없이 `index.html` 파일을 웹 브라우저에서 바로 열람할 수 있습니다.

```bash
# 로컬 개발 서버 실행 (선택사항)
python -m http.server 8080
```
